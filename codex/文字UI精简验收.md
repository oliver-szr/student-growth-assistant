# 三页文字与 UI 精简实施记录

本轮仅调整前端展示。未修改后端 API、数据库结构、排程规则或模型提示词；聊天消息、AI 推荐理由、解释与复盘原文继续使用原字段和原渲染方式。

## 已实施

- 顶部采用产品名＋小号口号，演示时钟放在全局导航；三页删除眉题和重复介绍。
- 规划优先卡片保留截止、剩余时长、重要性、风险；排序理由与目标关联移入详情。
- 聊天保留一条空状态示例，输入提示缩短；安排偏好成为档案入口。
- 日程保留七列和完整时间轴，取消任务块重复的正式任务文字，课程标为课程。
- 待确认候选保留前后变化与操作；变化数按任务标识去重；新增安排不冒充新增任务。策略统一为均衡、习惯优先、少改动，不再显示加权指标。
- 任务概览和执行工具合并为默认收起的任务与执行；新增表单按需打开。收起不会卸载表单。
- 复盘结果移至聊天之后，建议汇总到待确认建议，保留记录不足、AI 回退来源，证据按需展开。
- 档案目标表单按需打开，编辑定位到表单；停用偏好、其他目标、类别与关联、课程与保护时间、历史与备份默认收起。
- 共享文案和变化摘要集中在 frontend/src/uiCopy.js；安全渲染组件未修改。
