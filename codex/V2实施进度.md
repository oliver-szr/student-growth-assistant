## 当前 MVP 边界

- 目前是本地单用户软件，不含云同步、多账号或移动端原生应用。
- AI 习惯草案只基于用户确认的任务类别和计时开始时段。它不把计时记录解释成效率高低；样本不足时不推断。
- 长期偏好在表单中查看和修改，AI 观察以待确认草案呈现；任意画像文字自动提取规则、目标里程碑管理未进入当前版本。
- 习惯分析和周复盘目前由页面等待单次有上限的 API 请求；聊天排程已有后台进度、取消和重试，成长分析与复盘的后台运行、取消和重试留作下一轮。
- 周复盘只汇总用户确认的完成反馈；没有实际反馈时不会把日程上的计划当成已完成。
