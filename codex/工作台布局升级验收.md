# 三页工作台布局升级：实施与验收

本轮已实施布局升级，预览地址：http://localhost:5175/。本报告记录实际执行结果，不代表真实模型重新验收或 GitHub 发布。

## 界面与交互

- 三页统一使用 `WorkbenchLayout`：桌面左侧聊天、右侧结果；1024px 起双列，1023px 及以下切换聊天与结果。隐藏面板不卸载，保留输入、表单和会话状态。
- 内容最大宽度1440px，桌面边距24px、手机16px；聊天列320–440px，主要模块间距20px，圆角12px。
- 正文15px、模块标题18px、名称16px、次要信息13px；页面标题桌面28px、手机24px；控件统一44px。字号、间距与颜色集中在 `compact.css`，作为最终展示层加载。
- 规划：优先任务标题与卡片分离；安排偏好入口移入聊天标题；候选与确认栏位于右侧日程下方。选中方案有文字标记。
- 日程：七列完整显示08:00–22:00，无内部横向或纵向滚动；任务的分钟定位保持原算法。短任务优先显示名称，课程与任务可用键盘打开详情，查看完整名称、时间、锁定与分段信息。
- 复盘：概览数字、AI原文、目标进展及建议位于右侧；缺少事实显示“—”，不使用0代替未知数据。
- 档案：修改草案置于右侧顶部，偏好独占结果列整行；编辑表单保留在对应列表附近，工具区默认折叠。“示例”“仅供AI参考”标识保留。
- 三页共用聊天滚动组件：空状态不强行占满高度；接近底部才跟随新回复，阅读历史时显示“有新回复”。吸附仅在聊天面板能完整放入视口时启用。
- AI原文与安全格式渲染保留；未修改AI提示词、数据库结构、后端API或排程规则。

## 回归中修复的问题

1. 档案草案更新已有偏好时，旧实现将同一字段重复传入 `dict`，导致确认失败。改为明确合并旧值与修改字段，并新增接口回归测试；确认与重复确认均通过。
2. 重试完成后，新消息可能复用上一轮请求标识。重置对应标识并在编辑输入时重新分配，避免不同消息误被视为重复提交。
3. 取消按钮仅在运行ID存在时可用，避免提交尚未完成时发送无效取消请求。
