# 个人成长助手 V2 交付说明

日期：2026-10-04

## 产品现在可以做什么

产品从“帮用户排一周任务”升级为“从目标走到复盘，再用真实记录调整下一轮安排”。

- **看轻重缓急：** 首页把紧急程度、用户设定的重要性和目标关联分开展示。排序参考 DDL、剩余时长、课程与已安排时段中的连续空档，不会因为 AI 的判断擅自改写任务重要程度。
- **按真实情况调整估时：** 用户可开始、暂停或结束可选计时，也能跳过计时、手动填写实际投入。系统分别保存原始总估时、累计投入和预计剩余时长；计时停止不等于任务完成。
- **保存长期目标：** 用户可以设置方向、每周目标、衡量方式和优先顺序，把任务关联到目标。目标更改有历史版本，不会直接覆盖正式计划。
- **从记录提出习惯草案：** 后端先计算同类任务样本、天数和时段；至少 5 个不同任务、跨 3 天等条件满足后，AI 才能从已核验的观察中选择建议。用户可以查看证据、修改时段、采用或忽略。只有采用后，偏好才参与排程。
- **每周复盘：** 程序先整理已确认的完成次数、投入时间、目标进展和受阻原因，AI 再挑选重点和可讨论的下一步。数据不足时明确显示，不编造完成记录。
- **管理本地数据：** 应用可每日创建一次 SQLite 安全副本、最多保留 5 份；用户也可导出 JSON 并在导入前创建安全副本。备份不包含 `.env` 或 API 密钥。
- **三个清晰入口：** “今日安排”用聊天调整本周计划；“目标与成长”管理方向、目标和复盘；“我的资料”管理偏好、AI 草案、课程和备份。

## AI 做什么，程序做什么

AI 理解用户表达、从后端提供的统计观察中选择值得确认的个人习惯，并根据已核验事实组织周复盘。它不能直接写正式日程或保存偏好。

程序计算优先顺序、可用时段、样本数量、耗时建议和复盘事实；每个候选仍需通过排程约束校验，任务或长期偏好更改由用户确认后保存。计时开始时间只说明用户何时开始记录，不代表该时段更有效率。

- 后端：487 项测试通过；只有一条 `httpx` 与 Starlette TestClient 兼容性弃用提示。
- 前端：55 项测试通过；Vite 生产构建成功。
- DeepSeek 官方 OpenAI 兼容接口：真实浏览器验收通过任务理解、AI 推荐、方案确认与刷新恢复、习惯草案生成、用户确认保存偏好和 AI 周复盘。
- 浏览器以 `America/Los_Angeles` 时区运行，复盘周仍正确为北京时间演示周 `2026-10-05`；运行时错误为 0。
- 完整报告：personalized-ui-48bd87531b03414cb3843f707490f228.json（历史本地证据，不随公开仓库发布）。四张截图位于 `codex/evidence/`，包括初始界面、采用任务后的界面、习惯草案、周复盘。
- 所有 AI 与浏览器验收使用独立演示数据库和合成样例；没有重置或写入用户的正常数据库，也没有提交或推送 Git。

## 当前版本还没覆盖的内容

- 软件目前面向本地单用户，不含账号、云同步或跨设备自动合并。
- 用户可通过结构化表单编辑偏好；任意自然语言画像自动转换为规则并预览确认、目标里程碑管理暂未加入。
- AI 习惯观察以确认过的计时开始时段为基础，不推断“最佳效率时间”，也不靠一次记录改变长期画像。
- 成长分析和周复盘目前使用有时限的请求并在页面显示等待状态；聊天排程已有后台运行进度、取消和重试，分析与复盘的对应控制可在下一轮加入。
