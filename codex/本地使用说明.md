# 大学生成长助手：本地中文版本

本仓库已下载到 `大作业/codex/student-growth-assistant`，本地修改位于 `feat/chinese-localization` 分支。中文版本保留原有布局、排程规则、接口字段及数据库结构。

## 现在怎么打开

在项目根目录打开 PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\codex\启动本地版.ps1
```

然后访问 [本地页面](http://localhost:5173)。后端健康检查是 [api/health](http://127.0.0.1:8000/api/health)，接口说明是 [Swagger](http://127.0.0.1:8000/docs)。

启动脚本在后台运行服务；重复执行会识别自己启动的服务。需要同时打开浏览器时，在命令末尾加 `-OpenBrowser`。运行日志保存在 `codex/.runtime/`。

停止服务：

```powershell
powershell -ExecutionPolicy Bypass -File .\codex\停止本地版.ps1
```

停止脚本核对进程编号、启动时刻和程序路径，只停止该启动脚本记录的进程。端口被其他程序占用时，启动脚本会提示，不自动结束其他程序。

## 三分钟体验主流程

1. 在“任务”页添加两个任务，时长设为 60 分钟，截止时间设在准备演示的未来一周内。
2. 在“课程与保留时间”页添加课程，再添加休息或通勤时间。保留时间会限制排程，不显示为计划中的任务。
3. 在“周计划”页选择日期，勾选任务，点击“生成候选计划”。先检查安排，再点击“确认候选计划”。
4. 添加一个高优先级的临时任务，返回周计划，勾选原任务和临时任务，重新生成。旧正式计划在确认前保留。
5. 点击“查看变化说明”比较两版安排；AI 未配置时仍可看变化列表并确认。

时长需要是大于零的 30 分钟整数倍。界面和输入均使用北京时间；后端返回 UTC 属于同一时刻的另一种表示。AI 文字解释中引用的时刻按现有后端规则使用 UTC，界面会明确提示。

## 数据保存在什么地方

正常使用的数据保存在 `backend/data/app.db`，停止或重启服务不会清空。首次下载没有原开发数据库，本次只创建了空的本地数据库；浏览器验收数据保存在单独的 `codex/.runtime/acceptance-*.db`。

不要把 `.env`、数据库、`.venv`、`node_modules`、缓存或运行日志提交给同学，仓库已配置忽略规则。共享代码后，每位同学在自己的电脑建立环境和数据。

## 换电脑时安装依赖

本机已经安装，无需重复操作。其他电脑需要 Python 3.11 或以上、Node.js 20.19 或以上（或 22.12 或以上）。在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
npm.cmd --prefix frontend ci
```

使用 `.venv` 可以避免修改现有 Conda 课程环境。本次实测 Python 3.12.4、Node.js 24.15.0。

如果 npm 报 `ENOTCACHED`，检查 `npm.cmd config get offline`；确认是离线模式导致后，可以对本次安装加 `--offline=false`，无需改全局配置。

## 如何重新测试

后端测试会使用独立数据库，普通测试不调用付费 AI：

```powershell
Set-Location backend
..\.venv\Scripts\python.exe -m pytest
Set-Location ..
npm.cmd --prefix frontend test
npm.cmd --prefix frontend run build
```

真实浏览器验收需要先停止正常本地服务，释放 8000 和 5173 端口，然后执行：

```powershell
.\.venv\Scripts\python.exe -m pip install playwright
.\.venv\Scripts\python.exe codex\run_product_tests.py
```

验收使用本机已安装的 Microsoft Edge，无需下载额外浏览器。运行器生成随机身份和新测试数据库；强制浏览器 API 指向隔离服务，拒绝其他 API 源。结束后只停止自己启动的服务。验收日志、JSON 和截图保存在 `codex/evidence/`；不影响正常使用的数据，也不调用真实 AI 提供者。

## 可选 AI 配置

需要实际 AI 时，再按照原 README 将 `backend/.env.example` 复制为 `backend/.env`，填写有效密钥、网关地址和模型名称，随后重启后端。密钥只放在后端。本次没有配置密钥或进行真实模型调用；已验证未配置时的降级流程，提案成功和澄清界面使用模拟提供者响应测试。
