# 公开版使用与演示

## 从哪里开始

请从根目录 README 的安装命令开始，使用项目独立 `.venv`。前后端分别监听本机地址，仓库公开不代表已经部署在线服务。

默认演示使用匿名课表、虚构任务与习惯样本。日期为 2026-10-12 至 10-18，模拟当前时间为 10-14 18:00，北京时间；正常模式仍读取真实时间。

## 四分钟展示

1. **规划**：查看已有任务、DDL、课程和“现在先关注”，解释重要性和紧急性分别显示。
2. **我的档案**：输入“新增编程类别，编程尽量安排在周一至周五14:00–17:00，阅读目标改成每周两篇”。检查修改草案，再确认保存。
3. **规划**：新增“周五20:00前交实验报告，预计两小时，尽量周四下午做”；提出“必须周四14:00”以展示课程冲突，再改为一个可行要求。
4. 插入“明天12:00前交汇报稿，预计一小时，很重要”，观察候选变化；再说“今天累了，今晚不学习”，讨论取舍，确认方案。
5. **复盘**：补录任务完成或暂缓；检查事实、样本不足提示和习惯建议。完成记录与日程安排分别保存。

AI 回复依赖实际服务，时间和方案以校验后的卡片为准。缺少必要信息时补充回答，不把示例话术当作固定输出。

## 模型不可用时

仍可通过手动任务卡片及档案编辑管理数据。输入保留，页面提示失败；不宣称 AI 已完成理解或安排。可使用预览图片介绍界面，但不能将图片当作实时功能通过证明。

## 数据迁移与备份

升级前保留正常数据库、`backend/.env` 和自有课程文件。应用使用版本化迁移，SQLite 备份留在本地。通过“我的档案”导出 JSON 并在另一实例导入；不要将导出文件提交到 Git。

恢复会使旧候选和运行失效，重新打开会话后生成新草案。演示 `-Reset` 仅处理该脚本的演示实例，不重置正常数据库或其他预览实例。

## 发布记录

个人仓库保留原小组来源和提交贡献；不附新增许可证。正常数据、密钥、课程原件、日志、原始验收证据均排除上传。实际执行结果见本目录的《公开发布验收》。
