# 中文化与产品测试报告

日期：2026-10-03（北京时间）。来源仓库：`oliver-szr/student-growth-assistant`，基线提交 `58151c8`，工作分支 `feat/chinese-localization`。以下计数均来自本机实际执行，不沿用原 README 的历史结果。

## 修改范围

- 三个页面、表单、按钮、空状态、加载状态、校验提示及可访问名称改为简体中文。
- 待完成、已完成、已取消、优先级、重复方式和计划状态通过显示映射中文化；接口枚举不变。
- 星期改为周一至周日；保留原有北京时间转换和 ISO 数字日期。
- AI 变化说明默认请求 `zh-CN`；未配置或不可用时保持手动操作及计划确认可用。
- 中文错误提示保留机器可读的 `status/code/detail`；未知服务器文字不直接进入界面。
- 增加独立环境、可重复的验收工具、后台启动与停止脚本及中文使用说明。

没有更改后端业务代码、数据库结构或排程算法。原英文 README 保留，并增加中文使用入口。

## 产品验收覆盖

1. 三个页面的中文空状态和 `zh-CN` 语言标记。
2. 空白标题被真实后端拒绝，显示中文字段和纠正提示，数据库不新增任务。
3. 任务新增和编辑；修改说明时保留截止时间及原始英文接口枚举。
4. 课程、保留时间新增；AI 未配置时手动流程仍可使用。
5. 排程避开课程和保留时间；候选不自动成为正式计划；改变选择阻止确认。
6. 首次确认并从数据库读取正式计划。
7. 临时任务重排；确认前保留旧正式计划；中文变化列表及 AI 说明降级。
8. 确认替换方案后，旧计划标记为已替换。
9. 修改任务后，真实后端返回过期冲突；重新生成后恢复确认。
10. 单日无法容纳的任务不能生成完整计划，原正式计划保留。
11. 完成和取消状态不出现在排程选择中；刷新后仍能读回正式计划。
12. 浏览器模拟连接失败后出现中文提示，恢复连接并手动重试成功。
13. AI 提案先预览、放弃不写入；修改并应用后才通过真实接口保存。
14. AI 补充信息和不支持请求的中文提示，均不写入数据。
15. 390px 和 320px 窄屏的三个页面无横向溢出。

第 12 项使用浏览器网络拦截模拟断网，未做物理断网。第 13、14 项只模拟 AI 提供者响应，保存仍走真实后端；未验证真实模型质量、网关连通性或付费调用。其余核心流程连接真实本地 FastAPI 与 SQLite。浏览器时区刻意设置为洛杉矶，仍核对界面按北京时间显示。

## 代码审查及修复

只读审查检查了显示层与接口边界，未发现中文化改变核心确认语义。验收工具发现并修复了三处问题：无法严格证明测试服务身份、Playwright 回调参数被覆盖、用户前端配置可能指向其他后端。修复后使用随机标识、新建隔离库、强制 API 地址及请求拦截，完整重新执行验收成功。

## 当前产品边界与后续建议

- 排程是按截止时间、优先级、任务编号寻找最早连续空档；不拆分任务，也不回溯。无法排程不等于数学上绝对无解。
- 重新规划会安排整周所选任务，不冻结过去或已经开始的安排。演示建议选择未来一周，并勾选替换方案中需要保留的全部任务。
- 当前是本地单库 MVP，本次未验证公网部署、多用户权限或负载压力。
- 测试截图和日志只作为本地证据，已加入忽略规则；共享测试脚本即可由同学生成各自证据。

下一轮可让每位同学独立启动，再用真实课程任务试用一周，记录“找不到入口、理解不了提示、安排不符合习惯”的具体反馈。优先验证这些问题，再决定是否增加提醒、任务拆分等功能。
