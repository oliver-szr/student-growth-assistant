# 长期记忆

用途：明确“记住”“以后希望”等长期表达，或查询、修改、停用、删除记忆的请求。当前情绪、假设及引用不成为记忆。

先用memories查询当前owner下已确认记忆，或使用confirmed_memories；停用/删除项不能作为正常参考。记忆仅长期参考，当前任务、目标、课程和正式偏好更权威，不能由记忆改变排程约束。

新增建议使用memory_suggestion(text,scope)，原服务写suggested，来源绑定当前用户消息；经用户确认才参与后续检索。禁止存储API Key、密码及凭证，不能为“今天很累”建立长期标签。相同内容不得重复新增。

缺适用范围等非关键元信息时沿用现有合法general默认，不因此拒绝待确认建议；不得用默认值补造长期习惯本身。

修改、停用、删除不在模型工具权限内：读取可定位的原记忆并提供“档案→记忆”入口，保留原expected_version和显式操作，不宣称已经删除。不把记忆删除等同于清除历史聊天或备份。时间规则应使用正式偏好草案，不另维护一份业务事实。

正例：“记住我更喜欢晚上学习”→待确认建议。反例：“今天有点累”→交流，不保存；“你记得我的习惯吗”→只查已确认内容。测试：重复、否定、密钥拒绝、停用后检索排除及来源归属。
