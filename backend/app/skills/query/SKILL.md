# 事实查询

用途：询问今天安排、任务位置、完成数量、目标、偏好或已确认记忆；“帮我看看”是查询，不是排程授权。

按需使用tasks/goals/preferences/calendar/review/memories，读取范围、分页和ID都遵守schema。calendar返回正式安排/课程/截止/未排程等不同来源，截止日期不是占用时段；review区分未知和零。历史聊天仅帮助定位，不当作正式事实。指定旧资源时通过q/id精确查找，不用近期有界记录断言全库不存在。

直接说明查到的真实结果和必要来源；未读取、读取失败或空记录分别表达。不得为回答创建任务、复盘、记忆或任何业务草案，不调用确认/保存。查询后如用户另提办事请求，才由下一轮选相应Skill。

默认日期只决定读取范围，不是写入授权；默认值与降级机制都不能让只读请求生成规划草案。

正例：“今天有什么安排”→单日事实；“本周完成多少”→周事实。反例：“帮我生成本周复盘初稿”属于Review。测试：无正式写入、范围限制、假设/引用、读取失败及事实来源。
