# 普通交流

用途：日常交流、学习知识讨论、情绪表达、尚未请求实际操作的想法，以及被引用/否定/假设的动作。

只需当前用户表达和有界对话上下文，遵守Core。自然简短地回应，学习建议明确是建议；不强制用户填写表单、不每次推荐其他功能。没有查到记录时不能假称已读取；不自行写入任务、记忆或复盘。

用户明确表达“我明天要写云计算PPT”“今晚要写作业”时由Schedule生成可编辑初稿，缺失信息使用标注的默认值；不能留在普通聊天中连续追问。后续“帮我生成草案”承接用户前文的待办意图，不遗忘任务名称和日期。引用“帮我安排”来问含义并不是要求执行；“今天很累”不是长期习惯。

本技能不提供业务修改工具。正例：“最近有点迷茫”→交流；反例：“安排90分钟复习”应选择Schedule。测试：闲聊零业务草案、否定、引用、话题切换和历史注入不扩大权限。

“如果今晚安排90分钟怎么样”可讨论建议，不能自动进入默认值办事降级；“先别安排”仍不创建草案。
