## 指标、公式与时间

固定 Asia/Shanghai、周一00:00起，结束日不含。end_week 是最后一周周一，默认当前周，不允许未来周。执行事实不晚于项目时钟和区间结束；计划包含本周未来正式安排。跨月、跨年按日期而非浏览器时区归组。所有结果都是查询时有效记录的重算，不代表当时数据库快照。

| 指标 | 定义 |
|---|---|
| 计划任务数 | 当前 confirmed 正式片段中的可执行 Task ID 去重；每周及全范围分别去重，跨周任务不能把周数简单相加 |
| 计划分钟 | 正式可执行片段与对应区间交集的分钟总和，排除候选和 superseded 计划 |
| 确认完成数 | 未撤回合法 completed 反馈，按 completed_at 归周，每个 Task ID 留最新有效完成；旧完成时间缺失回退 occurred_at 并报告条数 |
| 部分完成任务数 | 区间内 partial 反馈的不同可执行 Task ID 数；不当作完成 |
| 实际投入 | 未撤回合法反馈的 actual_minutes 按 occurred_at 相加，包含 partial/postponed；计时不再累加 |
| 未知投入 | 无反馈或存在缺失耗时则完整实际分钟为 null；已知小计和缺失条数另列。合法历史0为已知零，现有写接口仍拒绝新增0分钟 |
| 取消 | 单列查询时全库 executable 的当前 cancelled 数；没有取消时间账本，周取消事件数为 null，不按 updated_at 猜测 |
| 历史完成率 | null；缺少不可变周初任务集，完成数/当前可变计划数不能当作历史完成率 |
| 类别占比 | 该类别已知分钟/全部类别已知分钟；分母为0时null，不代表包含未知部分的完整投入比例 |
| 估时差异 | 可配对任务全过程实际合计 - 完成反馈中保存的原始预计合计 |
| 估时偏差比例 | 合计差异/原始预计合计；不是逐任务比例的简单平均，也不用当前剩余分钟 |
| time目标 | 最新周有效反馈分钟，对照当前 weekly_target；缺反馈或缺耗时为未知，保留已知小计 |
| count/deliverable目标 | 最新周不同确认完成 Task ID 数，对照当前目标值，不按关联任务总数除算 |

类别归属使用反馈当时 family_snapshot 稳定标识，名称优先当前类别（包括改名/停用），其次历史名称；没有快照归“未分类”，不从现在任务类别伪造历史。当前关联任务状态独立显示，不作为历史目标进度。没有目标快照，不输出过去精确目标趋势，不自动修改目标状态。

## 去重、更正与缺失

- 父容器不进入执行、完成、计划分钟、目标工作量。子任务使用独立 Task ID，与普通任务同口径。父进度保持 done子任务/全部子任务，取消仍在分母。
- 反馈更正沿既有 supersedes_id/retracted_at 机制：旧行排除，新行生效；撤回的完成不保留。完成归 completed_at，投入归 occurred_at，跨周更正后重新查询两周均更新。不用当前 Task.status 反推历史；计时/日程结束不算完成。
- 估时配对需要范围内确认完成、原始估时可比、截至完成的全部有效投入已知，包含范围外早期部分完成。沿更正链找原始记录位置，晚补更正早期 partial 也能正确替换；祖先仅用于定位，不增加被撤回或未来投入。断链、循环、跨任务、估时不一致、多个有效完成事实等排除配对。
- 无效 outcome、负值/超1440分钟、非法部分完成剩余值排除；缺耗时保留为未知，不推断未开始任务“效率高”。
- 有效配对不足3项时仅展示已有事实和样本数，不生成类别规律。类别观察还要求至少2/3样本超时且加权偏差>10%，不声称效率提高或未来预测。原有耗时/习惯建议的独立阈值保持不变。
